- ALTA — Exposición del usuario y la IP del NVR a usuarios camera-scoped mediante el diagnóstico: GET /api/cameras/:id/diagnostics sólo exige canView (cameras.ts:162-170) y devuelve rtsp.mainUrlMasked/subUrlMasked = rtsp://<usuario NVR>:***@<IP NVR>:<puerto>/... (cameras.ts:224-225; hikvision.ts:1721-1724). La UI lo ofrece en cada tile de /live a todos los roles (LiveViewPage.tsx:1302-1305, 2056-2062; VideoPlayer.tsx:533-535, 589; CameraDiagnosticModal.tsx:71, 80).
