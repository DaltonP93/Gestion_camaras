# Instrucciones persistentes de VisionCore

@docs/AI_HANDOFF.md

## Uso de este repositorio

- El handoff importado define propósito, límites, estado y método de trabajo.
- Antes de modificar streaming o grabaciones, leer los documentos específicos enlazados allí.
- Si el cambio puede afectar un servidor, NVR, cámara, grabación, base de datos o sesión activa, detenerse y pedir autorización explícita antes de ejecutar acciones operativas.
